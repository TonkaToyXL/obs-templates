STEP 01 free download · no account

Grab the zip

Unzip somewhere you'll remember — Documents or Downloads both work.

STEP 02 copies files + opens this guide

Run the installer

Mac → double-click install.command
Windows → double-click Install.bat

STEP 03 needed for mic-reactive overlays

Flip on WebSocket

OBS → Settings → WebSocket → enable (port 4455).

STEP 04 400×400 bottom-right is a good start

Add the Browser Source

Sources → + → Browser → Local file → pick overlays/orb.html from your installed folder.

STEP 05 you're live — go stream

Talk into your mic

Orb should light up when you speak. Stuck? Set CONFIG.micInputName in the HTML to match OBS.
